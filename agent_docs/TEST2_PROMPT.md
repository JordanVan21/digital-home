# Task: Rebuild assets/test2.png in the 3D sandbox and make editing feel seamless

> Condensed archive of the follow-up brief (given in-session on 2026-10-17). It supersedes `SANDBOX_PROMPT.md` on: yaw limits, disabled Y movement, surface items locked to their parent, and the collision approach. Everything else in `SANDBOX_PROMPT.md` and `agent_docs/` still applies; CONTRACTS.md stays authoritative for type names; list every contract change.

**Goal:** `assets/test2.png` is the complexity benchmark. A fixture should recognizably reproduce that room, and the user should be able to rearrange it freely (spin 360°, lift, set a vase on a table, push a chair under a desk) without fighting collisions.

1. **Audit** (no code): install, typecheck, lint, tests; try every SANDBOX_PROMPT checklist interaction; write `agent_docs/SANDBOX_AUDIT.md` (layout, what works, broken, bugs, drift).
2. **Analyze test2.png** → `agent_docs/TEST2_SCENE_SPEC.md`: shell (shape, dimensions from reference objects, ceiling, every door/window/opening, materials, trim/built-ins); object inventory table (id, category, dims, x/z, yaw, support, material/colour, kind) including small decor; stacking graph; lighting & mood; camera (position, height, look-at, FOV); gap list (every missing capability; add anything the prompt doesn't mention).
3. **Fixture:** `test2-room.json` with parentId stacking and placement classes; catalog entries (CC0/self-authored with source + licence; placeholders + an "Assets needed" list otherwise; nothing with unclear terms); scene picker entry; "Match photo" camera preset; dev reference overlay (PiP or full-screen with opacity slider); headless capture script → `test-output/test2-render.png`.
4. **Editing upgrades**
   - 4.1 Continuous 360° yaw (accumulated deltas; stored normalized to (−π, π]); floor rotation ring dial (any camera angle incl. top-down); Shift 15° snap; Q/E ±15° (Shift 90°); numeric yaw field; optional 90° X/Z tilt for small decor only via a "decor orientation" control; rotation respects collisions.
   - 4.2 Direct drag of the object across whatever it rests on (gizmo stays for precision); vertical via gizmo Y or Alt+drag with a guide line and height readout (above floor / above surface); gravity settle on release onto the highest support below (per-object Float toggle); placement class `ceiling` (pendants, hanging plants; drop length); wall items slide along and up/down and cross corners onto the adjacent wall; arrow keys nudge 1 cm (Shift 10 cm), PageUp/PageDown vertical.
   - 4.3 Height-aware collision in scene-core: per-asset collision profiles (catalog + category defaults): solid, table (top slab + legs + open under-space), open (shelves = support surfaces, gaps free), flat (never collides with things on top, stays in room), soft (collides only with solids, slight soft–soft overlap); compound oriented boxes only; 3D OBB SAT plus wall, opening-clearance and polygon checks; slide via minimum translation vector (walls too); policy file block-and-slide (default) or allow-with-warning; Ctrl/Cmd during drag ignores collisions (flagged); contact tolerance; cheap broad-phase (grid or sorted AABB sweep, incremental); red outline on both colliders plus a short reason label, never by mutating shared materials.
   - 4.4 Stacking: support surfaces per asset (height, local polygon, optional max item height) with category defaults (tops, each shelf, sofa seats, bed top); while dragging, snap to the topmost surface under the footprint centre that fits; on release becomes child (undoable re-parent in the same entry as the move); no collision with its support but still with siblings; dragging off the edge detaches and settles; multi-level stacks; parent move/rotate carries descendants; deleting a parent settles its children (one undo entry; reject if a child is locked); allow-table of what may rest on what (default: fits footprint and shelf gap; large furniture can't).
   - 4.5 Exploration: damping, zoom to cursor, smooth preset transitions; double-click object/floor to re-target; F frame selection, Home frame room; walk mode (1.6 m, WASD + mouse look, stays inside, no passing through solids); walls fade smoothly; may switch to Drei CameraControls (note why).
   - 4.6 Multi-select (Shift-click, box select) and group move/rotate with group collision; Ctrl/Cmd+G persistent groups; alignment snaps (back-to-wall, edge, centre) with guide lines (Shift disables); resize from panel (w/d/h, aspect lock) with uniform-scaling rules; material/colour variants (per-instance cloned materials); shell appearance (wall paint, floor material — stored separately from immutable shell geometry; contract change); lights as objects (lamps/pendants emit, ≤2–3 shadow casters, on/off, day/evening preset); glass, sheer curtains, alpha-tested plants without sorting flicker.
5. **Performance:** 60 FPS while dragging the full test2 scene (plan for ~100 objects) on a laptop, measured and recorded in SANDBOX_AUDIT.md; instancing for repeated small assets where it helps while keeping per-object selection; small decor doesn't cast shadows; DPR ≤ 2; `frameloop="demand"` when idle if safe; drag validation broad-phase only, never blocks a frame, log if > 4 ms.

**Tests (scene-core):** yaw continuity across ±180° and multiple turns; vase on table (no collision with support, collides with sibling, detaches off the edge, settles to floor); multi-level stacks move/rotate/delete with undo; chair tucked under table valid vs intersecting a leg; slide into wall/sofa ends against it; gravity onto highest surface, Float disables; wall item crossing a corner; ceiling height limits; group move collision; every test2 object loads with zero error-severity violations.

**Deliverables in order:** audit + spec (report gaps, continue) → fix audit items → collision/support/stacking with tests → rotation/movement/gravity/nudges → camera → test2 fixture/catalog/overlay/Match photo/capture script → remaining 4.6 + gaps → performance pass with numbers. After each: typecheck + tests + short note (works / decided / still different from test2.png).

**Acceptance:** audit + spec exist and every gap is addressed or deferred with a reason; "Match photo" is recognizably test2 (layout, objects, stacking, colours, lighting) with `test-output/test2-render.png`; 360°+ spins both ways with no jumps; direct drag, vertical move, settling; vase on/off/back on table without false collisions; chair tucks under table/desk; sliding along sofa/wall; multi-select, group move, snaps, resize undoable; smooth camera, focus, frame keys, walk mode, smooth wall fade; 60 FPS recorded; original checklist still passes.
